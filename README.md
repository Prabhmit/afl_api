# AFL Data Fetcher (Dockerized R Project)

A containerized R-based data pipeline designed to **fetch, process, and store Australian Football League (AFL) data** locally. By wrapping the R environment in **Docker**, this project guarantees absolute reproducibility and eliminates the need to manually install R, system dependencies, or packages like `fitzRoy` on your local host.
